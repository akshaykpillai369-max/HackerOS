# HackerOS

HackerOS is a fictional hacker-style operating system interface built using HTML, CSS, and JavaScript.

It is designed to give a movie-style hacking experience directly in the browser.

## Features

- Hacker-style boot screen
- HackerOS desktop
- Terminal with basic commands
- Animated system monitor
- Network Scanner coming soon
- Password Generator
- Settings to change desktop Wallpaper
- Kali Linux-inspired desktop background

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone the repository.
2. Open `index.html` in your browser.
